# 项目品牌框模板约定

模板由**用户自备**（指令里 `模板：` 填文件夹，与参考库写法相同）；**技能仓库不维护用户模板目录**。文件夹内以后还可放其它资源，不限于品牌框。非品牌框构图样式仍按制作规范迁移，不临摹原品牌/店招框。

用户指令写法：见 [提示词模板 · 有模板](prompts.md#有模板)。用户**不必**在指令里写「无卖点壳／有卖点示意」等标签。

## 什么是品牌框

店招顶栏、底栏壳、整圈外框、官方角标壳等可复用身份层（颜色不限）。  
不算品牌框：产品、场景、代言人、本品主副标题、规格字、内容区卖点模块。

## 用户怎么交

指令里写 `模板：` + 文件夹路径（与 `参考库：` 同级写法）。可为总目录（如 `本项目模板`），其下按类分子文件夹（如 `头图品牌框/`）。文件夹内放 PNG 即可，不必自己做 slots.json，不必在指令里标注壳/示意。

## 模板前置（完整制作可含；也可单独执行）

与「参考库前置」同级：指令含 `模板：` 时，须在参考图校验 / 全库参考前置**之前**完成；也可单独只跑本前置（不生图、不跑参考）。失败则**立即停止**并反馈，不进入参考分析或生图。

单独指令见 [提示词模板](prompts.md#单独阶段)。完整制作若已有本项目锁定且未过期的模板校验结论与 slots，可复用，不重复生成槽位。

本前置输出：壳/示意路径、套用范围（默认主图01）、安全区占比、（如需）已自检锁定的 slots 路径与各槽 `max_chars`；登记到项目索引。

校验至少包括：

1. 模板路径可读；递归子文件夹能找到拟用的品牌框类图片。  
2. 能确定**可套版的壳**（见下节）。  
3. 有示意时能看清框上卖点落点（若有）；示意不当最终交付件。  
4. 默认套用范围：**主图01**（头图）；用户另行指定才改。  
5. 若需要框上填字：完成本前置内的 **slots 一次生成与满长自检**（见下）；未通过不得进入后续。

无 `模板：` 行：跳过本前置，按无模板规则执行。

## 执行者必须做的分析

1. **递归**读取模板文件夹及其子文件夹中的图片。  
2. 文件名可作初筛提示，**仍以看图为准**：  
   - 名含 `原图`：优先当作无卖点壳候选；  
   - 名含 `使用`：优先当作示意候选；  
   - 看图与文件名冲突时，以看图结论为准并登记理由。  
3. 示意常见两种（看图确认）：  
   - **品牌名 + 框**（栏上无卖点字）；  
   - **品牌名 + 框 + 卖点**（栏上有卖点字）。  
   示意若还带完整产品主视觉，仍只作版式参考，**不得当作最终交付成图**。  
4. **壳怎么定**：  
   - 优先用「原图」壳（空内容区、可叠）。  
   - 无「原图」时：仅当示意中间内容区可透明套版（无本品主视觉占满）时，可用该示意作壳。  
   - 无可用壳 → **校验失败，停止并反馈**。  
5. 常见两态：「原图」+「使用」→ 壳 + 示意；仅一张且可作壳 → 仅壳。  
6. 结合硬表决定卖点落点；默认只套 **主图01**。  
7. 登记识别结论（路径、壳/示意、套用编号、slots 路径、校验通过）到项目索引，供各产品共用。

无模板时：不临摹参考品牌框；**不**标「待套版」。

## slots 一次生成与自检（项目级，先于分产品制作）

需要框上填字时，在**模板校验通过后、多产品生图之前**（亦可在「模板前置」单独阶段完成），由执行者根据壳与示意**只生成一次** slots，并完成自检；通过后写入项目固定位置（如 `工作文件/_公共/头图品牌框.slots.json` 或索引登记路径），**各产品复用同一份**，不得每个产品再各写一套、事后再回来统一改槽。

生成要求：

1. 对照示意量出槽位 `box`、`align`、`max_chars`（按栏宽与字号估算，宁短勿溢）。  
2. `has_selling_points` 与硬表一致。  
3. **自检（未通过不得放行）**：  
   - 按每个槽的 `max_chars` **生成满字数检测文案**（可用无意义满长占位，如重复「测」至上限，或等长示例句），**每个槽都要填满再画一遍**，不得只用短句蒙混。  
   - 用壳 + 上述满长 texts 跑 `composite-frame`，看图确认：满长时仍在栏内、不裁切、不溢出、对比可读、不压住应露出的内容区。  
   - 任一槽满长失败 → 下调该槽 `max_chars` 或改 `box`/字号估算后重检，直至全部槽满长通过。  
4. 自检通过后锁定 slots；后续产品只填各自 `--texts`（且 ≤ `max_chars`），**不再改 slots 几何**，除非用户改了模板图或明确要求重做槽位。

## 卖点放哪里（硬表）

| 参考有卖点 | 模板情况（看图结论） | 做法 |
|---|---|---|
| 无 | 有示意且框上可写卖点（品牌+框+卖点） | 用壳套版；按示意把**本品**卖点写到框上；内容区不放卖点 |
| 无 | 仅壳，或示意仅为品牌+框（无卖点字） | 套壳；内容区不放卖点 |
| 无 | 无模板 | 不临摹参考框；内容区不放卖点 |
| 有 | 有示意且框上可写卖点 | 用壳套版；本品卖点写到框上；内容区不放卖点 |
| 有 | 仅壳，或示意仅为品牌+框 | 套壳；卖点放内容区 |
| 有 | 无模板 | 不临摹参考框；卖点放内容区 |

示意上的字须换成执行卡本品文案。执行卡框上卖点的**字数须服从该槽 `max_chars`**（及栏宽可读上限）；超长先改文案压缩，不把长句硬塞进槽、也不因此每个产品去改 slots。

## 何时套框、何时写框上卖点

默认只处理 **主图01**。壳会压住重叠像素，生图须预留安全区。

| 步骤 | 做什么 | 说明 |
|---|---|---|
| 1. 模板校验 + slots | 定壳/示意；需要填字则一次生成 slots 并自检通过 | 参考校验与分产品制作之前；失败即停 |
| 2. 文案/执行卡 | 框上卖点按 slots 的 `max_chars` 写短句；内容区按硬表 | 各产品只改文案，不改 slots |
| 3. 生图（内容层） | 生成未套框内容层；安全区避开壳的顶/底/边 | 不让模型画店招框 |
| 4. 审核/返修（已套框看） | 内容层返回后**立刻套框**（有卖点则带锁定 slots + 本产品 texts）再审核；压字、栏位、框上文案与内容问题**一并**列入返修 | 返修仍优先改内容层或 texts；slots 几何已锁定则不在返修里改，除非自检阶段漏改且用户授权重做槽 |
| 5. 返修后 | 改完内容层或 texts 后**重新套框**再看；通过才交付 | 避免交未套框或旧框版 |

命令：

```text
python scripts/ecom_files.py composite-frame <内容层.png> <壳.png> <输出.png>
python scripts/ecom_files.py composite-frame <内容层.png> <壳.png> <输出.png> --slots <项目锁定slots> --texts <本产品文案.json>
```

### 会不会压内容？

会。防压：生图写安全区；**审核看的是套框后的图**；压住与框上字问题一并返修。

### 「带卖点的框」何时出现？

不单独再生成一张模型画的带卖点框母版。硬表要框上卖点时：锁定 slots（一次）→ 各产品执行卡按 `max_chars` 写句 → 套框步填 texts。硬表要卖点在内容区时：生图写入内容区，套框只叠壳。

无真 alpha 时不做透明底（制作规范第5节）；与品牌框无关。
