# 全流程批量操作检查表

本表梳理文件操作，不代替制作规范，不降低保真、逐图查看或返修额度要求。脚本批量是一次调用内顺序处理，不等于图片模型并行。工具说明见 [脚本说明](../scripts/README.md)。

| 阶段 | 固定操作 | 文件结果 | 仍由AI完成 |
|---|---|---|---|
| 启动 | environment；集中加载必要规则和索引 | 当前环境记录 | 阶段范围、图片工具可用性判断 |
| 商品输入 | inventory | 图片指标/哈希、文档清单、坏图和重复内容提示 | 看原图、分SKU、核对资料与事实 |
| 素材 | archive、inspect；必要时浅深背景preview | 原件、检测、必要审查联系表 | 实际制作、视觉验收及选版 |
| 参考 | reference_cache批量采集尺寸、比例、编号、指纹和总览 | 每套共享缓存，仅更新变化类别 | 选套、逐图看参考、分析构图与页面任务 |
| 文案与执行卡 | json及prompt | 当前执行卡、实际完整提示词原文及哈希 | 商品适配、准确文案、风格与配色 |
| 生成 | 宿主任务批次；返回后archive及json | 原件、真实调用状态 | 图片工具生成；不能把提示词留存当作已调用 |
| 审核 | inspect和明确选图列表preview | 指标及必要审查预览 | 每张商品、标签、文案、构图一次查齐 |
| 返修 | 相关编号prompt、archive、json | 本次提示词和修复原件 | 按额度编辑、比较原件与修复版 |
| 交付 | export、inspect、preview、count、json、overview串联 | 独立图、预览、编号核对和总览 | 最终视觉复核及补充真实限制 |
| 追加 | 按索引定位，仅处理受影响列表 | 对应选版及总览更新 | 理解范围、事实更正和额度核对 |

## 此次梳理补齐

- 参考准备原先只有规则、没有固定入口：新增reference_cache.py，不再临时写尺寸采集、哈希及总览代码。
- 商品输入原先靠临时枚举：新增inventory。相同内容只提示，不删除、不推断SKU；参考不自动去重。
- 完整提示词原先靠逐张临时写命令：新增prompt批量原文留存，不代替真实调用记录。
- 透明底边缘检查可用preview的background参数制作必要浅深背景联系表，不修改原图或alpha，不默认逐张制造多份预览。
- 文件操作串联后，按逐项结果恢复失败项；图片成功返回但归档失败时不再次生图。

## 边界

选套、商品证据、逐图文案、商品保真和构图验收不自动化为脚本通过。缓存命中不允许省略原参考查看，像素检测不证明商品正确。新增调用的保真输入现另经compose固定组装与读取校验，详见产品保真组装说明；完整重跑版本策略仍未调整，不引入收费后端。

结构及临时夹具测试不代表真实成图回归或实际速度已验证。工具可用也不等于每次AI已使用；图片调用仍由宿主Agent编排。
